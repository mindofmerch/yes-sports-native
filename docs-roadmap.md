# Native Foundation Roadmap

## In place

- Expo and React Native project configuration for iOS and Android.
- Typed, file-based navigation with a worlds-first home screen.
- Dedicated routes for TD Vortex, Red Zone, History Echo, TD Zone, ATS Lab, and Gold Script.
- Reusable midnight-theme tokens and accessible touch targets.

## Next integration boundary

Connect each world to a documented backend response that includes season, week, matchup identity, source timestamp, retrieval timestamp, and data status. Render unavailable states explicitly. Keep projection calculations on the trusted backend and never ship vendor credentials in the app bundle.

## Release readiness still required

- Final registered application identifiers and app-store metadata.
- EAS build profiles, signing credentials, and store accounts.
- Verified backend auth/data policy and end-to-end device checks.
- Accessibility, offline, crash reporting, and store submission review.
